Frontend React (Vite + TS) do DABLIU. Contém o bootstrap do app, roteamento, estilos globais e as páginas principais.

## Summary

- main.tsx — entrypoint do React; renderiza `App` e importa `index.css`.
- App.tsx — shell do app (layout + sidebar) e rotas via `react-router-dom`.
- index.css — estilos globais (Tailwind).
- App.css — estilos adicionais do app.
- pages/ — páginas de navegação (Dashboard, Layouts, Produção, Administração).
- types/ — tipos TypeScript compartilhados.
- assets/ — assets estáticos usados no app.
