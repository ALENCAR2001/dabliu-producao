## Summary

- boot.md — Maestro session startup (gitignore, pull, memory, rules, context, greet).
- dispatch.md — sub-agent prompt assembly and multi-provider routing.
- agent-memory.md — long-term and session memory schemas and write rules.
- agent-decision.md — escalation when task briefs are ambiguous.
- review-loop.md — routes sub-agent output through Reviewer by change type.
- context-maintenance.md — `.context.md` and `docs/FEATURE-MAP.md` schemas.
- task-tracking.md — file-based todos for multi-step work.
- code-*-review.md — reviewer checklists (quality, security, coherence).
- *-self-review.md — persona self-review rubrics before handoff.
- README.md — skill index and authoring schema.
- assets/ — shell scripts used by boot (OpenCode CLI configuration).
