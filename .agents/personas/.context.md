Specialized AI role definitions. Each persona file declares identity, playbook, handoff format, red lines, and frontmatter for model routing (`preferredModel`, `modelTier`, `humor`).

## Summary

- maestro.md — orchestrator; sole user interface; delegates all work.
- architect.md — plans implementations and defines before/after states.
- coder.md — writes software following approved plans.
- reviewer.md — validates plans and code quality, security, coherence.
- contextualizer.md — produces `.context.md` files and `docs/FEATURE-MAP.md`.
- README.md — persona registry and schema for new personas.
